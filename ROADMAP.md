# Roadmap

Terminal condition: full functional parity excluding subscriptions/licensing; no claim of parity before real behavior checks.

1. Evidence: REA/Hopper identity, read-only UI observation, official feature/schema inventory.
2. Base selection: evaluate licensed open-source engines against the feature matrix before custom implementation.
3. Editable local document, shape/text tools, selection/transform, history, layers, persistence/export.
4. Hierarchy, frames/flex layout, vectors, typography, styles, images, components/libraries, variables/themes.
5. Document interoperability, graphics/PDF/HTML export, slides/presentation.
6. AI providers/local models, tool calling/MCP, sessions, scoped permissions and recovery.
7. Browser/reference import, code workflow, sharing equivalent, desktop integration and packaging.
8. Execute parity acceptance suite, data-loss/error tests, keyboard/accessibility and performance checks.

See docs/FEATURES.md for evidence and docs/TRACKING.md for work identifiers. Not all rows are implemented.
