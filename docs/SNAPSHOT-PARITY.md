## Independent implementation under verification

Core `exportPenSnapshot` runs the existing loss-detecting `.pen` writer, extracts its loaded image and GLSL content, emits generated relative paths, and returns the editable design plus dependency assets. Original source references are retained only in the dependency-preview metadata, not in the serialized document. Two different source URLs with the same basename stay separate; repeated references to one source share a file while retaining paint-specific uniform overrides. Intentionally empty shaders remain empty and do not become failing file references.

The app uses the existing ZIP and browser/native save pipeline. Snapshot preparation captures a separate export payload; it does not save, rename or mark the open document clean. The modal opens with its dependency data ready, retains content while closing, closes on document replacement/unmount, and remains open after a cancelled destination choice. Export errors are reported; unsupported content retains the writer’s explicit refusal. Multi-page `.pen` export remains unsupported.
