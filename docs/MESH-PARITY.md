# Mesh paint parity

Reference: actual `/Applications/Pen.app` 1.2.21, inspected 2026-10-30. OpenPencil supplies implementation infrastructure, never reference behavior. Full Mesh design/functionality acceptance remains open.

## Observed reference behavior

Mesh is inside Gradient's subtype chooser, alongside Linear, Radial and Angular. Its default Grid 2 × 2 means three columns and three rows of vertices. The popup has a five-by-five cell chooser, mirrored/independent tangent controls, Outline Off/On, a row-major color grid and Shuffle Colors. Selecting a vertex adds Reset Position, Reset Curve and a color editor. Selected edges expose both endpoints' tangent handles. A lone selected color is unchanged by Shuffle Selected Colors. Shift-clicking palette colors adds/removes vertices; several selected colors show Selected Points and Mixed. An executed three-vertex shuffle permuted red/green/blue within that subset and left white untouched; native Undo restored the four original colors. Private captures: `pen-mesh-multiple-selection-reference.jpg`, `pen-mesh-selected-shuffle-reference.jpg`.

Changing the grid resets all point positions and removes explicit handles. The old color array repeats in row order to fill the new grid; it is not resampled spatially. Shuffle permutes the existing colors. These results were read back through actual Pen's document API after native actions. An all-red nine-vertex probe changed the canvas and palette while leaving the inspector's Mesh swatch as a fixed spectrum icon.

The private two-by-two explicit-handle fixture was saved, closed and reopened through actual Pen's native File menu, then read back with its four primary colors and handles intact. This verifies preservation of the reference fixture, not Open Pen acceptance.

Private evidence: `local-evidence/pen-mesh-popup-reference.png`, `pen-mesh-reference.pen`, `pen-mesh-reference-renders/R5YdJB.png`, `pen-mesh-reference-renders/vt98C.png`. Extracted vendor assets/source remain private and are not implementation dependencies.

## Independent implementation

SceneGraph stores normalized mesh positions, relative Bezier handles and per-vertex RGBA colors. Copies isolate nested edits for Undo. The renderer tessellates Coons patches and clips the resulting paint through the existing fill/stroke paths. Mesh is offered in the compact Gradient menu; Diamond remains an advanced-editor option. The inspector shares selected points, mirroring and outline settings with canvas editing. Grid/color edits use the existing property history; dragging uses owned previews with commit/cancel.

Supported `.pen` reading/writing retains grid, colors, handles, paint opacity, visibility, blend modes and vertex variable references. FIG stores a solid preview for other readers plus validated Open Pen metadata. Vertex references travel with colors through grid changes and shuffling; a direct color edit detaches only its reference, and conversion out of Mesh clears vertex bindings. Stale vertex references cannot silently recolor a replacement solid during `.pen` export. Figma's ordinary paint setter removes obsolete vertex bindings and does not present them as whole-paint aliases.

FIG instance paint/vertex-binding overrides carry the existing plugin metadata on occurrence claims, including explicit clearing. Reopen/component-sync regressions cover replacement aliases, moved points/handles and conversion to solid. A scaled-stroke regression exposed geometry in the Mesh payload overwriting the occurrence scale; export and restore now project paint fields only. The executed8→16px scale/reopen case also retains scaled dash geometry, cap and join.

## Executed evidence and limits

The direct independent 256 × 256 primary-color, implicit-handle probe matches all 65,536 reference pixels. The integrated export pipeline renders at 2× and downsamples; its measured sample colors differ by up to one RGB byte, with exact alpha. That is a remaining mismatch. Explicit straight handles, warped grids, transparency, larger grids and all blend combinations do not yet have complete reference image acceptance.

Eleven browser workflows passed: fill/stroke grid edits and Undo, vertex alias resize/edit/conversion with Undo, canvas point dragging while retaining the popup, mirroring/outline controls, Mesh/Linear conversion, ordinary-gradient regression paths and the reviewed canvas snapshot. The Mesh canvas snapshot uses zero allowed pixel differences so a border/handle change cannot hide in the usual whole-image tolerance. Format menus settle before subsequent keyboard input. Unit/regression checks cover schema rejection, copies, handle geometry, tangent commit/Undo/cancel, vertex alias preservation, FIG and `.pen` round trips, stale-reference refusal and instance overrides. These checks establish the covered browser and model paths; they do not establish every native interaction.

Installed native execution: changed the fill grid and undid it, dragged its center vertex, changed the first bound vertex to #112233, then used File → Save As to create `native-mesh-saveas-proof.pen`. Close → Recents → reopen retained the visible mesh and inspector values X32/Y32,256×256,80% opacity. Actual Pen read the saved file with its 3×3 grid, moved center (reported as [0.562,0.5469]), first literal #112233, remaining $Ink center alias and Ink=#AA4488. The stroke retained its independent 3×3 grid,16px Inside and80% opacity. Its native popup also resized to Grid3×1; Undo restored the clean saved state. Private captures: `open-pen-native-mesh-saved.jpg`, `open-pen-native-mesh-reopened.jpg`, `open-pen-native-mesh-stroke-resized.jpg`.

The actual Pen grid chooser was measured as144px wide with20px cells,4px gaps and a current/hover size caption. Open Pen now follows those dimensions and preview behavior; selected rows use Point/Handles and24px action buttons. Six browser workflows passed after this correction. Installed native inspection confirmed Point/Handles,24px action rows and the smaller chooser; its placement was then changed to open above the trigger, as in Pen, and verified in the installed final build (`open-pen-native-mesh-grid-final.jpg`). Full glyph/border comparison remains open.

A zero-height Mesh PATH renders blank in actual Pen, while the same Solid path draws and a one-pixel-high Mesh path draws. The initially suspected blank-line parity bug is therefore refuted for the measured PATH case; no arbitrary shader mapping was introduced.

Still open: complete popup/glyph/border comparison; keyboard behavior across every control; exact rendering for the cases above. The current reader deliberately refuses dimensions beyond the observed UI range of two through six vertices per axis; support for larger valid external meshes remains an acceptance gap. SVG mesh export explicitly refuses instead of producing an invisible paint; PNG and editable formats are the current paths.
